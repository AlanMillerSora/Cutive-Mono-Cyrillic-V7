# V7 — контрольные изображения

Все сравнения V6.020 / V7 — один масштаб, один рендерер (PIL/FreeType),
одинаковые поля.

| Файл | Что показывает |
|---|---|
| `alphabet-caps.png` | заглавный алфавит: V6 сверху, V7 снизу |
| `alphabet-lows.png` | строчный алфавит: V6 сверху, V7 снизу |
| `changed.png` | только изменённые буквы: V6 сверху, V7 снизу |
| `words.png` | контрольные слова (программирование … длинношеее) |
| `sentences.png` | обязательные предложения и смешанный текст |
| `extended.png` | расширенная кириллица: Ѐ…ӂ |
| `latin-reuse.png` | 25 переиспользованных пар (латиница коричневым) |
| `app/foot-*.png` | foot 11, 12, 13, 14, 16, 18, 20, 24 px |
| `app/kitty-*.png` | kitty 11–24 px |
| `app/vim-14.png` | Vim в foot, 14 px |
| `app/code-14.png` | VS Code 1.144.0, 14 px |
| `app/extended-20.png` | расширенная кириллица + Nerd fallback, foot 20 px |
| `app/large-14.png` | семья Large в foot, 14 px |
| `app/installed-foot-14.png` | установленная семья, foot 14 px |
| `app/installed-kitty-14.png` | установленная семья, kitty 14 px |

Скриншоты приложений сделаны в реальном Hyprland/Wayland-сеансе; шрифт
подключён через fontconfig. Для матрицы размеров использовалась копия
релиза с тестовым именем семьи (контуры идентичны), чтобы не трогать
установленную V6 до финальной проверки; `installed-*` — уже с
установленной V7.
