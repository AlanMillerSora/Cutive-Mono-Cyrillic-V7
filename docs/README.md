# Cutive Mono Cyrillic

Кириллическая версия **Cutive Mono** (Vernon Adams) — тот же печатный
typewriter-характер, но русский, украинский и белорусский текст больше не
проваливается в fallback.

Это **неофициальный форк**. Он не связан с автором оригинала и не является
релизом Google Fonts. Оригинальная лицензия — SIL Open Font License 1.1,
см. `docs/LICENSE`.

---

## Что сделано

* Латиница, цифры и пунктуация **не перерисованы**: в собранном TTF контуры
  всех 452 исходных глифов совпадают с оригиналом до последней точки
  (проверяется `source/tools/verify.py`).
* Нарисован полный русский алфавит + Ё/ё, а также украинские Ґ ґ Є є І і Ї ї,
  белорусская Ў ў, македонские/сербские Ѐ ѐ Ѝ ѝ Ј ј Ѕ ѕ Ѓ ѓ Ќ ќ Љ љ Њ њ Џ џ.
* Добавлена расширенная кириллица с диакритикой: Ӑ ӑ Ӓ ӓ Ӗ ӗ Ӝ ӝ Ӟ ӟ Ӣ ӣ Ӥ ӥ
  Ӧ ӧ Ӯ ӯ Ӱ ӱ Ӳ ӳ Ӵ ӵ Ӹ ӹ и другие композиты (база + комбинируемый знак).
* Пунктуация: № и ₽.
* Кириллица моноширинная: advance width **1240** у всех букв, как у
  латиницы; комбинируемые знаки — 0 (иначе NFD-текст разъезжался бы).
* Работает NFC и NFD: для пар «буква + U+0300…» собран GPOS mark-to-base,
  а композиты существуют отдельными глифами.

## V7

Полная ревизия кириллицы. Вес, латиница, метрики и покрытие не менялись.

* **К/к** — собственная каппа: К 1105 (было 1210), к 986 (как н), засечки
  396; больше не донорный K/clipped k.
* **х** — 813 вместо 774; ширина 920 и толщина 96 сохранены.
* **Ц/ц** — широкая нижняя планка 165–1075 / 200–1084, хвост 246;
  ширина 1032/986, как П/п.
* **Щ/щ** — хвост-засечка по центру стема; ширина 935/910.
* **Џ/џ** — U-тело + центральный выносной; **Ҷ/ҷ** — исправлены
  U+04B6/04B7 (Che with descender, не Zhe+breve).
* **Б/б, Ь/Ъ/Ы, ь/ъ/ы** — чаши подняты до x-height (830), б получила
  выносной 1180 и нормальную засечку.
* **З/з** — вертикальные терминалы; **Ч/ч** — убрана скрытая засечка;
  **Ґ/ґ** — L-образный выгиб; **Ђ/ђ, Ћ/ћ, Љ/љ, Њ/њ** — чаши/глубины
  приведены к единому принципу.
* 25 контуров переиспользованы из латиницы; Д/д, Ж/ж, Э/э, Я/я —
  утверждённые варианты сохранены.
* Проверки: 452/452 латиницы, 128/128 хинченных, 577 cmap, обе семьи,
  OTF, NFC/NFD, foot/kitty 11–24 px, Vim и VS Code 14 px; откат на V6
  проверен.
* Версия **7.000**; установлены обе семьи. Разбор — `docs/V7.md`,
  аудит — `docs/V7-GLYPH-AUDIT.md`, техотчёт —
  `docs/V7-TECHNICAL-REPORT.md`, копии — `docs/V7-LATIN-REUSE.md`,
  установка/откат — `docs/V7-INSTALL-ROLLBACK.md`, образцы —
  `specimens/v7/`.

## V6

Ремонт стыков: в десяти буквах с чашами (Б Ъ Ы Ь б в ъ ы ь я) между стемом
и чашей оставалась белая щель 34–54 ед. — из-за направления контуров
заплатка стыка вычиталась вместо сложения; плюс круглые стыки (Ж, Д, Л, У)
проедали штрихи. Строчная **к** переведена из латинской k (bbox 0…1182) в
x-height (0…813). **З/з** приведены к габаритам О/о, у **Д** убран выход над
капле-линией. Полировка: засечки стемов приведены к латинским 396, чаши
ь/ъ/ы опущены на базовую, убраны остриё у / выход под базовую у / хвост У
укорочен, Ш/Щ/Д выровнены, у Ѓ ѓ Ќ ќ появился острый (его не было из-за
бага), у џ — верхняя перекладина. И, главное для чтения: кириллица теперь
**хинтится** тем же
ttfautohint, что и латиница (раньше латиница несла инструкции, а
кириллица нет — на 14 px русский текст был на 6–7 % бледнее и заметно
мягче английского). Вес и латиница не менялись.
Разбор — `docs/V6.md`, образцы — `specimens/v6/`.
**V6.020 сохранена для отката** (сборка V7 — см. раздел V7 выше). В 6.010 К и х снова взяты из
латиницы (`docs/V6-01.md`), в 6.020 **Ц/ц** получили тело из перевёрнутой П/п
и хвост как у Щ (`docs/V6-02.md`). Латиница, вес и метрики не менялись.

Две семьи в установке:

* **Cutive Mono Cyrillic** — обычная (x-height 813);
* **Cutive Mono Cyrillic Large** — кириллическая строчная на 6,4 % выше
  (x-height 865), для чтения на 14 pt; латиница та же.

## V3

Типографическая ревизия без изменения толщины. Ключевое: у одиночных
стемов (г, т, л, ч) стопы стали широкими, как у латинских r/t/u; у Ж
ветви крепятся к краям стема (узел разгружен); у Д узкая верхняя
перекладина и лапки; у Ю чаша шире и перекладина доходит до счётчика;
у Я нога больше не пересекает счётчик. Вес, латиница и метрики не
менялись. Образцы: `specimens/v3/`, откат на V2 — `backup/v2-fonts/`.

## V2

Версия 2 — визуальная ревизия. Главное изменение: чаши строятся не из
абстрактного суперэллипса, а **масштабируются из контуров оригинальных
o/O**, поэтому изгибы и контраст буквально взяты у латиницы. Переработаны
Д д, Ж ж, Л л, Т т, У у, Ф ф, Ц ц, Ч ч, Ш ш, Щ щ, Ъ ъ, Ы ы, Ь ь, Э э,
Ю ю, Я я, З з, Б б, В в, Г г, Й й. Добавлены сербские Ђ ђ Ћ ћ.

Старая версия лежит в `backup/v1-fonts/` — откат одной командой, см.
`INSTALL-ARCH.md`. Образцы: `specimens/v2/`.

## Дизайн

Геометрия снята с оригинала и перенесена в параметрический кит
(`source/design/kit.py`):

| параметр | значение |
|---|---|
| UPM | 2048 |
| cap height | 1171 |
| x-height | 813 |
| overshoot | 17 |
| толщина стема (caps / lowercase) | 95 / 94 |
| горизонтальные штрихи | 86 |
| засечка | капсула 396 × 86, радиус 43 |
| чаша | суперэллипс, показатель 2.1, толщина ≈ 92 |

Из латиницы взяты не только пропорции, но и сами фрагменты: Н = H, О = O,
С = C, Е = E, А = A, В = B, Р = P, Т = T, Х = X, М = M, К = K, а также
а, е, о, р, с, х, і, ј, ѕ. Остальные буквы собраны из тех же примитивов
(стемы с капсульными засечками, чаши, диагонали, скруглённые терминалы),
поэтому русский текст остаётся в одном ритме с английским.

## Сборка

```bash
cd Cutive-Mono-Cyrillic
python3 -m venv .venv
.venv/bin/pip install fonttools glyphsLib ufo2ft skia-pathops uharfbuzz pillow ttfautohint-py

.venv/bin/python source/build.py              # TTF (+ хинтинг через ttfautohint)
.venv/bin/python source/tools/otf.py          # OTF (CFF)
.venv/bin/python source/tools/verify.py       # контроль качества
.venv/bin/python source/tools/specimens_v6.py   # образцы
.venv/bin/python source/tools/export_source.py  # обновить .ufo/.glyphs
```

`source/build.py` — единственный источник истины: он собирает кириллицу,
добавляет её в оригинальный TTF, пересобирает cmap/name/OS-2, генерирует
GPOS и в конце прогоняет `ttfautohint` по готовому файлу (латиница при
этом рендерится бит-в-бит как раньше, кириллица получает те же
инструкции). Экспортированные `.glyphs`/`.ufo` — редактируемая копия
готовых контуров для Glyphs/FontForge.

## Лицензия и имена

Шрифт распространяется по SIL OFL 1.1. В оригинальном `OFL.txt` Reserved
Font Name не объявлен, но форк всё равно назван иначе —
**Cutive Mono Cyrillic**, — чтобы его нельзя было спутать с официальным
Cutive Mono. Copyright и упоминание модификации внесены в name-таблицу.
