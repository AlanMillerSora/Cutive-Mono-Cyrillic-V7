# V7 — аудит и решения по глифам

Дата аудита: 2026-10-30. База: V6.020 (SHA-256
`aaf8154e…55f7`). Решение по каждому глифу — одно из четырёх:

* **reuse** — взят готовый латинский контур;
* **keep** — контур сохранён без изменений (проверен и признан качественным);
* **adjust** — контур доработан оптически;
* **new** — построена новая конструкция.

## Что не менялось

* Толщина: стемы 96, горизонтали 86/82, чаши 92, засечки 396×86.
* UPM 2048, advance 1240, cap 1171, x-height 813, descender −350/−330.
* Латиница: 452/452 контура бит-в-бит.
* Утверждённые Д/д, Ж/ж, Э/э, Я/я — не откатывались.
* U+04C1/04C2 (Ӂ/ӂ) — контуры побайтно те же, что в V6.020.
